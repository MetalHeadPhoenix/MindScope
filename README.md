**Organize your learning journey across all areas of life — fields, subfields, and sequential steps.**

MindScope is a powerful desktop application that helps you structure your learning paths, track progress, and maintain notes across multiple domains like technology, music, business, and personal development.

![MindScope Screenshot](assets/screenshot.png)

## ✨ Features

- **🏗️ Hierarchical Organization** - Create fields, subfields, and detailed steps
- **📊 Visual Metro Map** - Beautiful, intuitive interface inspired by metro maps
- **🎨 Dark Mode Support** - Easy on the eyes, day or night
- **📝 Step Tracking** - Track state (New, In Progress, Pending, Completed) with timestamps
- **📌 Rich Notes** - Add detailed notes to each step
- **💾 Persistent Storage** - Local data storage (works offline)
- **📤 Export/Import** - Backup and restore your data
- **🔍 Zoom Controls** - Zoom in/out for better visibility
- **🖱️ Hover Tooltips** - Quick preview of step notes
- **🚀 Cross-Platform** - Works on Windows, macOS, and Linux

## 🚀 Installation

### Download Installer

Download the latest version for your operating system from the [Releases page](https://github.com/yourusername/mindscope/releases).

| Platform | Download |
|----------|----------|
| **Windows** | `MindScope-Setup.exe` |
| **macOS (Intel)** | `MindScope-1.0.0-x64.dmg` |
| **macOS (Apple Silicon)** | `MindScope-1.0.0-arm64.dmg` |
| **Linux (AppImage)** | `MindScope-1.0.0-x86_64.AppImage` |
| **Linux (Debian)** | `mindscope-1.0.0-amd64.deb` |

### Windows Installation

1. Download `MindScope-Setup.exe`
2. Run the installer
3. Follow the setup wizard
4. Launch from Start Menu or Desktop shortcut

### macOS Installation

1. Download `MindScope-1.0.0.dmg`
2. Open the DMG file
3. Drag MindScope to Applications folder
4. Launch from Applications

*Note:* If you see "App can't be opened because it's from an unidentified developer", right-click the app and select "Open".
